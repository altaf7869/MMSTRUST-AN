# Mewas Charitable Trust - Angular

1. Install Node.js 18.19+ or 20+
2. npm install
3. npm start   (http://localhost:4200)
4. npm run build   (upload dist/trust-site/browser)

Data: src/assets/data/*.json
Images: src/assets/images/
Privacy: "privacy": {"shortNames": true, "hideReceipt": true} in trust-data.json
